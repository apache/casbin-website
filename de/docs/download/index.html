Download

Der offizielle Apache Casbin Release ist das Quellcode-Archiv, das von The Apache Software Foundation veröffentlicht wird. Für Installation über Paketmanager und erste Schritte siehe Get Started.

Neueste Version​

  • Apache Casbin 3.11.0-incubating Quellcode-Release (PGP-Signatur, SHA-512)
  • Schlüssel zur Signierung von Releases (KEYS)

Ihren Download verifizieren​

Verifizieren Sie das Quellcode-Archiv immer mit seiner SHA-512-Prüfsumme und PGP-Signatur vor der Verwendung. Die Signaturschlüssel befinden sich in der oben genannten KEYS-Datei, und der ASF-Verifikationsleitfaden erklärt, wie beide überprüft werden.

Ältere Releases​

Jedes Apache Casbin Release bleibt in dem ASF-Verteilungsarchiv verfügbar. Nur das neueste Release wird unterstützt.

Die Inkubation ist für alle neu akzeptierten Projekte erforderlich, bis eine weitere Überprüfung ergibt, dass die Infrastruktur, die Kommunikation und der Entscheidungsprozess stabilisiert sind, in einer Weise, die konsistent mit anderen erfolgreichen ASF-Projekten ist. Obwohl der Inkubationsstatus nicht unbedingt ein Spiegelbild der Vollständigkeit oder Stabilität des Codes ist, zeigt er an, dass das Projekt noch nicht vollständig von der ASF befürwortet wurde.
