하이브리드 접근 제어 모델

Apache Casbin은 PERM 메타모델(Policy, Effect, Request, Matchers)을 기반으로 접근 제어 모델을 정의하기 위해 CONF 파일을 사용합니다. 구성 파일을 수정하여 인증 메커니즘을 변경하거나 업그레이드할 수 있습니다.

유연한 정책 저장소

Apache Casbin 정책은 메모리, 파일 또는 데이터베이스에 저장할 수 있습니다. MySQL, Postgres, Oracle, MongoDB, Redis, Cassandra, AWS S3 등 수십 개의 저장소 백엔드를 지원합니다. 어댑터의 전체 목록을 확인하세요.

언어 및 플랫폼 간 호환성

Apache Casbin은 Golang, Java, PHP, Node.js, Python, .NET, Rust 등 여러 언어로 구현되어 있습니다. 모든 구현체는 동일한 API와 동작을 공유합니다.

Apache Casbin 온라인 에디터 사용해 보기

인터랙티브 온라인 에디터를 사용하여 실시간으로 Apache Casbin 모델 및 정책을 작성하고 테스트해 보세요. 다양한 접근 제어 모델을 시도하고 결과를 즉시 확인할 수 있습니다.

전체 에디터 열기

Policy Persistence

Apache Casbin은 어댑터를 통해 정책을 저장합니다. 라이브러리를 가볍게 유지하기 위해 어댑터 코드는 기본 파일 어댑터를 제외하고 메인 라이브러리에서 분리되어 있습니다. 서드파티 어댑터 기여를 지원합니다. 자세한 내용은 어댑터 목록을 참조하세요.

대규모 Policy Enforcement

일부 어댑터는 필터링된 정책 로딩을 지원합니다. 이는 Apache Casbin이 지정된 필터를 기반으로 스토리지에서 정책의 일부만 로드할 수 있음을 의미합니다. 이 기능은 모든 정책을 한 번에 로드하는 것이 비효율적인 대규모 멀티 테넌트 애플리케이션에 유용합니다.

Role Manager

Role Manager는 Apache Casbin에서 RBAC 역할 계층 구조(사용자-역할 매핑)를 처리합니다. Apache Casbin 정책 규칙이나 LDAP, Okta, Auth0, Azure AD 등 외부 소스에서 역할 데이터를 로드할 수 있습니다. 라이브러리를 가볍게 유지하기 위해 Role Manager 코드는 기본 구성 요소를 제외하고 메인 라이브러리에서 분리되어 있습니다. 사용 가능한 모든 역할 관리자을(를) 확인하세요.

누가 Apache Casbin을 사용하나요?

Fortune 500 기업부터 새로운 스타트업까지 수백 개의 프로젝트가 Apache Casbin을 사용합니다. Apache Casbin으로 무엇을 만들 수 있는지 확인하려면 이 앱들을 살펴보세요!

**서비스 약관**

Apache Casbin (Incubating)은 Apache Incubator의 후원을 받아 The Apache Software Foundation(ASF)에서 인큐베이팅 중인 프로젝트입니다. 모든 새로 승인된 프로젝트는 인프라, 커뮤니케이션 및 의사 결정 프로세스가 다른 성공적인 ASF 프로젝트와 일관된 방식으로 안정화되었음을 추가 검토가 나타낼 때까지 인큐베이션이 필요합니다. 인큐베이션 상태는 코드의 완전성이나 안정성을 반드시 반영하는 것은 아니지만, ASF가 프로젝트를 완전히 지지하지 않았음을 나타냅니다.
