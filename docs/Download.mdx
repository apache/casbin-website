## Verify your download

Always verify the source archive with its SHA-512 checksum and PGP signature before use. The signing keys are in the KEYS file above, and [the ASF verification guide](https://www.apache.org/info/verification.html) explains how to check both.

## Older releases

Every Apache Casbin release stays available in [the ASF distribution archive](https://archive.apache.org/dist/incubator/casbin/). Only the latest release is supported.
